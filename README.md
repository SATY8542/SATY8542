## 🚀 Featured Project

### 🫁 Lung Disease Diagnosis Using Machine Learning

An applied computer vision system developed for the multi-class classification of pulmonary conditions from radiographic chest images, augmented with explainability techniques for transparent inference.

<p>
  <img src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white" alt="Python" />
  <img src="https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white" alt="TensorFlow" />
  <img src="https://img.shields.io/badge/Scikit--Learn-F7931E?style=flat-square&logo=scikitlearn&logoColor=white" alt="Scikit-Learn" />
  <img src="https://img.shields.io/badge/Pandas-150458?style=flat-square&logo=pandas&logoColor=white" alt="Pandas" />
  <img src="https://img.shields.io/badge/NumPy-013243?style=flat-square&logo=numpy&logoColor=white" alt="NumPy" />
</p>

#### Key Features & Architecture
- **Multi-Class Disease Classification:** Accurately classifies chest images into four categories: **COVID-19**, **Normal**, **Pneumonia**, and **Tuberculosis**.
- **DenseNet121 Transfer Learning:** Employs DenseNet121 architecture for feature reuse, parameter efficiency, and fine-grained feature representation.
- **Grad-CAM Explainability:** Generates Gradient-weighted Class Activation Mapping (Grad-CAM) visual heatmaps to identify decisive anatomical image regions.
- **Prediction Confidence Scoring:** Outputs calibrated probabilistic confidence scores alongside diagnostic classifications.
- **Web-Based Prediction Interface:** An interactive web portal for seamless image uploading, inference processing, and diagnostic display.

> 📌 **Project Status:** Under preparation for open-source publication. The repository link will be updated here once publicly available.  
> ⚠️ *Disclaimer: Developed for academic and research exploratory purposes; not clinically validated for diagnostic use.*
